# Security & Confidentiality Policy

This repository is intentionally sanitized for public portfolio use.

## Never include

- Employer/client production source code
- Real financial message layouts or VAN/bank specifications
- Production DDL, table/column names, stored procedures, or SQL copied from work
- Real URLs, IP addresses, ports, DNS names, account IDs, certificates, keys, tokens, passwords, or secrets
- Internal logs, incident reports, completion reports, architecture screenshots, or monitoring exports
- Internal CI/CD workflow files copied from work
- Customer, transaction, card, image, or personal information

## Allowed portfolio material

- Newly written sample code implementing generic concepts
- Fictional protocol fields and synthetic data
- Generalized architecture diagrams drawn from scratch
- Architecture Decision Records describing trade-offs without proprietary details
- Public documentation that explains engineering reasoning

## Clean-room rule

All code in this repository must be written from scratch for the portfolio. Do not copy/paste internal source and then rename classes or fields.
